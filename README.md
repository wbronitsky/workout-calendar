# Workout Calendar

Personal Peloton / strength plan (Jul–Sep 2026).

**Live:** https://wbronitsky.github.io/workout-calendar/

## Add to phone (home screen applet)

1. Open the live link above on your phone
2. **iPhone (Safari):** Share → **Add to Home Screen**
3. **Android (Chrome):** menu ⋮ → **Add to Home screen** / **Install app**

ICS download: [workout-calendar-2026-jul-sep.ics](./workout-calendar-2026-jul-sep.ics)

Click workouts in the HTML to mark them done (saved in that browser).
