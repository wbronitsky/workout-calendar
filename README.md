## Add to iPhone home screen (barbell icon)

Firefox on iPhone currently ignores custom home-screen icons and shows a letter instead ([Firefox bug](https://github.com/mozilla-mobile/firefox-ios/issues/33663)).

To get the barbell icon, add once from **Safari**:

1. Open the live link in Safari
2. Tap **Share** (square with ↑)
3. Tap **Add to Home Screen**
4. Tap **Add**

ICS download: [workout-calendar-2026-jul-sep.ics](./workout-calendar-2026-jul-sep.ics)

Tap workouts to mark them done (saved in that browser).
